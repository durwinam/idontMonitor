# idontMonitor v2.3.5

## Changes
- HTTP login is allowed for direct-IP and other deployments without TLS, rather than being rejected by the login endpoint.
- On the login page only, HTTP displays a localized security recommendation in English or Persian asking the operator to enable HTTPS and configure an SSL/TLS certificate.
- The recommendation automatically fades after five seconds and is not shown over HTTPS.
- Existing account credentials remain preserved during ordinary upgrades; random credentials are generated by the installer only for a fresh account/install path, not on every upgrade.
- Monitoring calculations and telemetry logic were not intentionally changed.

## Security note
HTTP does not encrypt credentials or session traffic in transit. The notification is a recommendation, not a security control. HTTPS remains strongly recommended, especially on untrusted networks.
