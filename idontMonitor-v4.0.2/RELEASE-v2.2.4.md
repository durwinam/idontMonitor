# idontMonitor v2.2.4

## Improvements
- Telegram bot asks each authorized administrator to choose Persian or English before showing the main menu.
- Language choice is stored per Telegram user and can be changed later from the bot menu.
- Added live CPU utilization percentage to server status and system resource messages.
- Expanded Persian localization for login and VPS management UI, including RTL layout.
- Improved iPhone safe-area, responsive login form sizing, and motion/reduced-motion handling.
- Added fallback Persian labels and error states for VPS summary cards.

## Validation
Source syntax, JavaScript syntax, test scripts, and release archive integrity are checked during packaging. A live Telegram token and target VPS are not available in this build environment, so Telegram delivery and privileged VPS operations require deployment validation.
